# Memoria y reglas en el repositorio

Todo va en el repositorio, nunca en `C:\Users\...`. Si el sistema ofrece memoria local, ignorarla.

- Reglas: `.claude/rules/*.md`
- Memoria: `.claude/memory/*.md`

**Preferir reglas sobre memoria.** Usar memoria solo para datos personales, evolutivos o no universales. Si hay ambigüedad, preguntar al usuario.
